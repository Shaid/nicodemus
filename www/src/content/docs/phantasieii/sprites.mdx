Every sprite Phantasie II shipped: **80 monsters** (from `MSTR1.PAT`/
`MSTR2.PAT`) and **16 playable races** (from `PARTY1.PAT`/`PARTY2.PAT`),
each in its normal and attacking pose. Card titles are each sprite's
extracted frame name exactly as it comes out of the sprite bank's manifest —
index-prefixed (`0-SKELETON`, `11-ORC`), the same naming convention this
project uses for Phantasie I. There's no separate name-lookup file for these
frames: the confirmed name (from `PHANT.PRG`'s monster/race name tables — see
[Characters, Items & Combat](/phantasieii/characters-and-combat/)) is baked
directly into the frame name at extraction time. Click any card to enlarge.
