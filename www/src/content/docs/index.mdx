**Phantasie** is Strategic Simulations, Inc.'s 1985-1987 first-person dungeon
RPG trilogy. This site reverse-engineers all three games' graphics, data
tables, dungeon grids, and combat/scripting logic from the original shipped
files — Phantasie I and III on the Amiga, Phantasie II on the Atari ST (it
never got an Amiga release) — and documents the decoders this project ships.
The exhaustive byte-level notes, disassembly citations, and paths-tried
evidence trails live in each game's own `docs/phantasie*/` in the main repo;
this site is a curated, human-readable companion to that research.

## What the three games share

Phantasie I and II are read by **one byte-identical dungeon/scripting
engine** — the same grid layout, star/action/message trigger format, and
opcode table (Phantasie II adds four extra opcodes of its own), differing
only in which item/monster name tables and party-vs-Amiga-vs-ST details get
plugged in. All three games additionally share one bitplane pixel-encoding
foundation and the same 12-bit RGB palette scheme, with Phantasie III's own
`.CMP`/`.CSH` container adding RLE compression on top. Those formats are
documented once, in **[Shared Formats](formats/)**, rather than repeated in
each game's section.

Where the games diverge — Phantasie III's own combat RNG and stat layout,
Phantasie II's Atari ST executable format, each game's own item/monster/race
tables — gets its own page in that game's section.

## Source of truth

These pages are a curated summary. The exhaustive, byte-level research notes
live in the main repository (not part of this site) — and when a page here
disagrees with them, **the raw notes win**:

- `docs/phantasie/graphics-formats.md`, `data-tables.md`, `dungeon-format.md`,
  `scripting-engine.md` — the byte-level specs, covering all three games.
- `docs/phantasie/stx-extraction.md` — the Phantasie II `.stx` disk-image
  extraction method.
- `docs/phantasie/implementation-plan.md` — the build-out plan and current
  status.
- `docs/phantasie/TODO.md` — the single status surface for open work.
